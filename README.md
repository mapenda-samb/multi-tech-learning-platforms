# multi-tech-learning-platforms
My first HTML/CSS practice project a page about tech learning platforms 
## what i built
A simple about tech-learning-platforms (Coursera,Freecodecamp,Scrimba) with a sign in form.
## what i practiced
 - HTML structure: headings,paragraphs,forms,links
 - Organizing a page into sections
## notes
  - Sign-in form and buttons are clickable and the sign-up link open,but pressing will not create an account - this is a front-end only practice project (HTML,CSS, no backend or JavaScript yet).
## Why this project?
  - It puts tech self-learning platforms in one place, so you do not have to search for each one. Click the Coursera logo and it takes you straight to Coursera, and so on for the rest.
